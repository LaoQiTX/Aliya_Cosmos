项目启动:

1.open Server live
2.npx start (起应用)

3.npx electron-packager . MyApp --platform=win32 --arch=x64 --out=dist --overwrite --icon=QDW.ico
参数:
MyApp 是app的应用名称；
platform 是适配的平台;
out是输出的文件夹路径，当前配的是项目文件夹下的dist；
overwrite是覆盖旧文件；
icon是app的图标;
